Project 01 · AI Customer Support Triage & Resolution

RelayDesk

A human-aware support automation system designed to classify incoming requests, retrieve grounded context, draft responses, and route uncertain or risky cases to human review instead of pretending every AI prediction should be autonomous.

In Development

Before

Eight routine decisions before one ticket moves.

The manual baseline is modeled as: read the request → categorize it → assess priority → search documentation → draft a response → decide whether it is safe → assign or escalate → record the action. RelayDesk targets the repetitive steps while preserving judgment where confidence or risk demands it.

Read & classify
Search context
Draft response

Automation

Structure first, generation second.

AI-assisted work

Classification, intent extraction, response drafting, and context-aware recommendations are model-assisted but must resolve into validated application data.

Deterministic controls

Schemas, thresholds, business rules, retries, escalation paths, and audit events remain explicit system logic instead of being delegated to free-form model output.

Architecture

A workflow with a real human branch.

Webhook / API
AI + Structured Output
Retrieval + Policy
Auto Action / Human Review

Planned stack

n8n, Python, FastAPI, Pydantic, local Ollama plus optional cloud providers, retrieval storage, and a polished review dashboard.

Human-in-the-loop

Reviewers will be able to approve, edit and approve, reject, or escalate a suggested action. The workflow resumes only after the chosen decision is recorded.

Results

Measured, not invented.

No performance figures are claimed yet because implementation and benchmarking are not complete. Results will be generated from a labeled synthetic test dataset and clearly identified as benchmark results rather than production-client outcomes.
