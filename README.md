## 🌈 How I Work

1. **Discover** — map the existing business process, pain points, and measurable goals.
2. **Design** — define workflow architecture, data contracts, and human approval points.
3. **Automate** — implement orchestration, integrations, agents, and structured outputs.
4. **Safeguard** — add validation, retry/fallback logic, and escalation paths.
5. **Evaluate** — test realistic cases, inspect failures, and measure results.
6. **Handoff** — document operation, monitoring, and maintenance.

```text

├── workflows/
├── schemas/
├── prompts/
├── evals/
├── tests/
├── docs/
├── architecture/
├── demo/
```

Not every folder is created before it is needed. Projects are built one at a time so each system is genuinely functional before the next project begins.
